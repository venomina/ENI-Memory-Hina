ENI - MEMORY - Accueil

Bienvenue sur le site du Memory de l'ENI. Venez jouer avec nous, et faites le meilleur score possible !


Règles du jeu :


  • Retournez deux cartes : si les images sont identiques, le jeu laisse les cartes visibles.
  • Si les images sont différentes, les cartes se retournent faces cachées là où elles étaient.
  • La partie est terminée lorsque toues les cartes ont été assemblés par paire.


Si vous voulez vous souvenir de votre score, inscrivez-vous via le formulaire ! Le jeu garde les 5 meilleurs scores. Si vous souhaitez relancer une partie, appuyez sur la barre espace.
